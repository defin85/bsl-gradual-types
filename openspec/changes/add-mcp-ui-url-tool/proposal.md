# Change: add-mcp-ui-url-tool

## Зачем
HTTP UI `bsl-agent` может быть запущен на автопорту (например, `BSL_AGENT_HTTP_ADDR=127.0.0.1:0`), и фактический `http://localhost:<port>` становится известен только после bind.

Сейчас получить URL можно:
- из логов;
- через CLI `bsl-agent ui url` (требует shell-доступа).

Но MCP-клиент (в т.ч. LLM), подключённый к `bsl-agent` по stdio, не всегда имеет возможность исполнять shell-команды. Нужен read-only MCP tool, который вернёт URL локального UI, чтобы LLM/клиент мог подсказать пользователю ссылку для открытия в браузере.

## Что меняется
- В `bsl-agent` добавляется read-only MCP tool `ui_url`, возвращающий URL HTTP UI текущего инстанса (если UI включён и доступен).
- Tool НЕ запускает UI и не меняет конфигурацию; он только читает текущее состояние.

## Влияние
- Затронутая спецификация: `openspec/specs/mcp-bsl-agent/spec.md` (добавляется требование на tool `ui_url`).
- Затронутый код (на стадии реализации): `bsl-agent` (MCP server tools).

## Не цели (Non-goals)
- Не добавляем mutating tools и не меняем sandbox/read-only модель.
- Не превращаем MCP tool в “инспектор” HTTP UI; только выдача URL (адрес/порт).
