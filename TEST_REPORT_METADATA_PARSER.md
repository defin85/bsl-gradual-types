## 🔍 Найденные проблемы и ограничения

### 1. Вложенные синонимы не извлекаются

**Описание:**
Парсер не извлекает синонимы из вложенных структур `<Synonym><v8:item><v8:content>`.

**Пример:**
```xml
<Synonym>
    <v8:item>
        <v8:lang>ru</v8:lang>
        <v8:content>Заказ наряды</v8:content>
    </v8:item>
</Synonym>
```

**Текущее поведение:** `synonym = None`
**Ожидаемое поведение:** `synonym = Some("Заказ наряды")`

**Оценка критичности:** ⚠️ **НИЗКАЯ** — синоним опционален, базовая функциональность работает.

**Рекомендация:** Добавить парсинг вложенных синонимов в будущих итерациях.

---

### 2. Неиспользуемые переменные в коде

**Описание:**
В `parser.rs` есть неиспользуемая переменная `in_properties`.

**Файл:** `backend/src/data/loaders/config_metadata_parser/parser.rs:44`

**Рекомендация:** Удалить или использовать переменную, применить `cargo fix`.
