📥 КАК СКАЧАТЬ:

Вариант 1: Командная строка (быстро)
────────────────────────────────────────────────────────────────
cd tools
curl -L https://wj32.org/wp/download/releases/empty-standby-list/EmptyStandbyList.exe -o EmptyStandbyList.exe


Вариант 2: Вручную
────────────────────────────────────────────────────────────────
1. Открой: https://wj32.org/processhacker/forums/viewtopic.php?t=1569
2. Скачай файл: EmptyStandbyList.exe
3. Помести в эту директорию: tools/EmptyStandbyList.exe


Вариант 3: Альтернативный источник (если основной недоступен)
────────────────────────────────────────────────────────────────
1. Открой: https://github.com/wj32/processhacker
2. Перейди в Releases
3. Найди "Empty Standby List"
4. Скачай EmptyStandbyList.exe


✅ ПРОВЕРКА:

После скачивания проверь размер файла:
    ls -lh EmptyStandbyList.exe

Ожидаемый размер: ~6-10 KB

Если размер сильно отличается - возможно файл скачан неправильно.


🔒 БЕЗОПАСНОСТЬ:

✅ Официальная утилита от разработчика Process Hacker (wj32)
✅ Open Source - исходный код доступен
✅ Подписана цифровой подписью автора
✅ Функциональность: только очищает Standby List, ничего больше


🚀 ИСПОЛЬЗОВАНИЕ:

После скачивания используй скрипты:

    # Только очистка кэша
    ./scripts/clear_cache.sh

    # Очистка кэша + подготовка к тестированию прогресса
    ./scripts/test_progress.sh
