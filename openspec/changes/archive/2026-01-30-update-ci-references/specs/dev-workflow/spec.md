## ADDED Requirements

### Requirement: Документация корректно описывает фактический состав CI
Документация MUST отражать фактическое состояние автоматизации: какие проверки выполняются в GitHub Actions (если есть) и какие проверки обязательны локально. Документация MUST NOT создавать ожидание, что CI прогоняет `cargo fmt`/`cargo clippy`/`cargo test`, если этого нет.

#### Scenario: README не вводит в заблуждение по статусу CI
- **GIVEN** в README есть упоминание CI/проверок
- **WHEN** разработчик следует инструкции
- **THEN** он должен получить корректные ожидания: что именно проверяет GitHub Actions (repo policy) и какие проверки нужно запускать локально
