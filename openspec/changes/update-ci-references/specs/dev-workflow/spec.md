## ADDED Requirements

### Requirement: Документация не заявляет наличие CI/CD при отсутствии конфигурации CI
Если в репозитории отсутствует конфигурация CI (например, `.github/workflows/*`), то документация MUST явно указывать, что проверки выполняются локально, а CI отсутствует или планируется.

#### Scenario: README не вводит в заблуждение по статусу CI
- **GIVEN** в README есть раздел о проверках качества
- **WHEN** разработчик следует инструкции
- **THEN** он должен получить корректные ожидания: какие проверки доступны локально и что CI не выполняет их автоматически
