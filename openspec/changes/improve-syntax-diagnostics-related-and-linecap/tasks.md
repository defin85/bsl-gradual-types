- [x] 1.2 `openspec validate improve-syntax-diagnostics-related-and-linecap --strict --no-interactive`.

## 2. Implementation (syntax)
- [x] 2.1 Вынести единый финальный шаг нормализации синтаксических diagnostics (merge → rewrite/enrich → line-cap → sort).
- [x] 2.2 Применить line-cap ко всем синтаксическим diagnostics в `ParseResult.syntax_errors` (включая semicolon/`Новый` эвристики) с явной политикой приоритетов.
- [x] 2.3 Реализовать masking строки (комментарии `//`, строковые литералы) для безопасного поиска ключевых слов без смещения индексов.
- [x] 2.4 Обобщить правило `Для`: span на первый неожиданный токен между `По` и `Цикл`, сообщение “ожидается `Цикл`” даже при мусорном токене.
- [x] 2.5 Enrich related для незакрытой `Попытка` при распознавании по `ParseError` (добавлять “Начало блока: Попытка” если related отсутствует).
