## Closed implementation hotspots

1. `shared/src/ir/semantic_facts.rs` и `analysis-v2/src/type_inference_v2.rs` теперь materialize-ят canonical type/receiver/member/definition facts внутри одного IR snapshot; configuration symbols дополнительно несут canonical `metadata_path`.
2. `analysis-v2/src/lib/snapshots.rs` и `analysis-v2/src/lib/analysis_api.rs` публикуют exact current-revision semantic artifact из того же snapshot и fail-closed на stale/miss вместо stale/degraded substitute.
3. `bsl-runtime` shared services для `completion`, `hover`, `definition` и `signatureHelp` читают derived exact semantic index на analyzed path и не восстанавливают semantic truth локально из текста, runtime `semantic_facts` или consumer-local repository state; `diagnostics` остаются canonical batch consumer того же snapshot/revision.
4. `backend`, `web`, `bsl-agent` и `cli` остались transport wrappers над shared runtime contract и общей bounded observability taxonomy; CLI inline `complete` / `info` принимают публичный `--path` для canonical module-context semantics и берут exact owner/type truth из shared runtime без adapter-local facet collapse, а Web inline surfaces используют checked-in `filePath`/`file_path` contract вместо synthetic path там, где нужен module context.
5. docs, execution matrix и machine-readable validation assets приведены к реально shipped contract и checked-in evidence после закрытия runtime gap `xgg.3`.
