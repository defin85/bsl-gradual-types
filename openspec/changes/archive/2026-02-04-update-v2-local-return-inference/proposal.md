# Change: Усилить локальный вывод return-типа в IntelliSense v2 (sound + union + SCC)

## Why
Сейчас в `bsl-analysis-v2` присутствует локальный вывод типа вызова `F()` для функций текущего модуля, но он носит MVP/эвристический характер:
- возможна несоответствующая семантике BSL ситуация, когда функция по факту может завершиться без явного `Возврат`, но выводимый тип не включает `Неопределено`;
- разные `Возврат` с разными типами дают `Unknown` вместо полезного `union`;
- вычисление при взаимных вызовах/рекурсии опирается на ограничение количества итераций, что делает результат зависящим от эвристик, а не от специфицированного алгоритма;
- в результате hover/completion/type-at-position для реальных модулей (особенно общих модулей) может показывать неверный или неоправданно “пустой” тип.

Это противоречит целям проекта (“промышленная” применимость, корректность и предсказуемость вывода типов) и ожидаемому контракту v2 pipeline как единственного источника истины.

## What Changes
- Зафиксировать в спецификации v2 контракт локального вывода return-типа для функций текущего файла:
  - поддержка вызова до объявления (forward reference) и вызовов неэкспортных методов внутри модуля;
  - soundness: учёт неявного `Возврат Неопределено`, если возможен выход из функции без явного `Возврат`;
  - union: объединение типов из нескольких `Возврат` (без деградации в `Unknown`, если типы конкретны).
- Заменить эвристический “локальный резолвинг” на детерминированный алгоритм:
  - построение локального call graph;
  - вычисление strongly connected components (SCC);
  - решатель fixed-point/worklist внутри SCC (для взаимных вызовов и рекурсии);
  - гарантированная терминальность/детерминированность результатов.
- Интегрировать результат во все v2 consumers (hover/completion/diagnostics/type-at-position) через единый v2 snapshot.

## Impact
- Affected specs:
  - `bsl-intellisense-v2` (добавление требований по локальному return inference)
- Affected code (после утверждения и реализации):
  - `analysis-v2/src/type_inference_v2.rs` (локальные summaries, solver, union)
  - тесты `analysis-v2/` (регрессионные сценарии)

## Non-Goals
- Складывать локальные (file-local) функции/процедуры в глобальный `SignatureIndex` конфигурации/платформы.
- Делать межфайловый interprocedural inference по произвольным неэкспортным вызовам (это отдельная задача).
- Менять публичные контракты API/LSP в рамках этого change (только улучшение точности типов).
