# Test Progress Skill

Автоматизированный навык для тестирования прогресса парсинга типов платформы 1С.

## Описание

Этот skill автоматически:
1. Очищает Windows File System Cache для "холодного старта"
2. Проверяет наличие собранного LSP сервера
3. Копирует LSP сервер в vscode-extension/bin/
4. Даёт инструкции по запуску VSCode Extension

## Использование

```bash
/test-progress
```

Или через Skill tool:
```
Skill(command: "test-progress")
```

## Что делает

### Шаг 1: Очистка кэша
- Проверяет наличие `tools/ClearFileCache.ps1` (PowerShell скрипт)
- Или проверяет наличие `tools/EmptyStandbyList.exe`
- Запускает очистку Windows File System Cache
- Требует прав администратора (появится UAC prompt)

### Шаг 2: Проверка сборки
- Проверяет наличие `target/release/bsl-lsp-server.exe`
- Если нет - выполняет сборку: `cargo build --release --bin bsl-lsp-server`
- Показывает прогресс компиляции

### Шаг 3: Копирование LSP сервера
- Копирует `target/release/bsl-lsp-server.exe` → `vscode-extension/bin/`
- Показывает размер файла и timestamp

### Шаг 4: Инструкции
- Даёт пошаговые инструкции для запуска VSCode Extension
- Показывает ожидаемый прогресс парсинга

## Требования

- Windows 10/11
- GitBash или совместимая среда
- Права администратора (для очистки кэша)
- Собранный Rust toolchain

## Ожидаемый результат

После выполнения skill:
1. ✅ Windows File System Cache очищен
2. ✅ LSP сервер собран и скопирован
3. ✅ Готовность к тестированию прогресса

Затем:
1. Открой `vscode-extension` в VSCode
2. Нажми F5 (Run Extension)
3. В новом окне VSCode открой конфигурацию 1С
4. Наблюдай прогресс парсинга в статус-баре (1-2 минуты)

## Troubleshooting

### Не удалось очистить кэш
- Проверь наличие `tools/ClearFileCache.ps1`
- Подтверди UAC prompt (нажми "Да")
- Проверь права администратора

### LSP сервер не собирается
- Проверь, что Rust toolchain установлен: `rustc --version`
- Запусти вручную: `cargo build --release --bin bsl-lsp-server`
- Проверь логи компиляции на ошибки

### Не вижу прогресс в VSCode
- Убедись, что кэш очищен (запусти skill снова)
- Проверь, что LSP сервер обновлён в vscode-extension/bin/
- Перезапусти VSCode Extension (закрой debug окно и нажми F5 снова)
