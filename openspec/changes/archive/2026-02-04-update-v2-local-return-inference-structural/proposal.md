# Change: Довести v2 local return inference до “полной готовности” (структурные типы + рекурсия)

## Why
В `bsl-analysis-v2` локальный вывод return-типа для функций текущего файла уже реализован (call graph + SCC + fixed-point, union по нескольким `Возврат`, implicit `Неопределено`).

Однако текущая реализация хранит “варианты типов” как строки (`type_name()`), из‑за чего при транзитивной передаче типа через локальные вызовы возникают ложные platform-типы с именем вида `"Строка | Число"`, а не структурный `ResolutionResult::Union`.

Это делает поведение:
- менее корректным с точки зрения типовой модели (union теряет структуру при `A() { return B(); }`, где `B()` уже union);
- менее предсказуемым для consumers (hover/diagnostics могут показывать “правильную строку”, но семантически это другой тип);
- недостаточно закрытым по требованиям “рекурсия/взаимная рекурсия”: отсутствуют тесты на транзитивные union и mutual recursion в рамках v2 local return inference.

Цель этого change — довести компонент до “IDE‑grade” готовности: структурная корректность типов + тестовое покрытие для ключевых сценариев.

## What Changes
- Зафиксировать в спеках v2 требования к **структурному** представлению локального return-типа:
  - транзитивное распространение union/типов через локальные вызовы (`A()` возвращает `B()`);
  - корректная и детерминированная политика для рекурсии/взаимной рекурсии;
  - запрет на деградацию union в “platform type с именем, содержащим `|`” как побочный эффект сериализации `type_name()`.
- Переработать локальный solver return-типа так, чтобы он оперировал **TypeResolution/ConcreteType**, а не строками:
  - объединение типов через “join”/flatten union, с детерминированной нормализацией;
  - soundness по implicit `Неопределено` сохраняется.
- Добавить тесты, которые проверяют не только строковый `type_name()`, но и **структуру** `TypeResolution`:
  - `A() { return B(); }`, где `B()` даёт union → `A()` даёт тот же union (структурно);
  - взаимная рекурсия `A()<->B()` возвращает детерминированный результат по специфицированной политике и не зависает.

## Impact
- Affected specs:
  - `bsl-intellisense-v2` (доп. требования для local return inference)
- Affected code (после утверждения и реализации):
  - `analysis-v2/src/type_inference_v2.rs`
  - тесты `analysis-v2/` и/или `backend/tests/` (интеграционные регрессии)

## Non-Goals
- Изменять глобальный `SignatureIndex` (локальные функции остаются file-local).
- Менять публичные API/LSP контракты (улучшается точность типов без изменения интерфейсов).
- Рефакторить/переопределять базовую семантику `bsl-types` вокруг `SpecialType::Undefined` (в рамках этого change фиксируемся на поведении v2 local inference).
