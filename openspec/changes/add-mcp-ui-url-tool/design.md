## Требования
- Tool должен быть read-only.
- Tool должен работать без shell-доступа у клиента.
- Tool должен возвращать URL для текущего инстанса `bsl-agent` (к которому подключён MCP-клиент), а не “все инстансы”.

## Решение
Добавить MCP tool `ui_url`, который возвращает:
- `enabled: bool`
- `ui_url: string | null`

Источник правды для URL:
- использовать runtime registry, который пишется самим `bsl-agent` при успешном старте HTTP UI (после bind), и читать запись по `pid` текущего процесса.

Почему registry:
- порт может быть автоподобран (`:0`), значит “узнать порт” можно только после bind;
- registry уже кроссплатформенно работает в целевой среде (WSL/Linux) и не требует внешних утилит.

## Поведение
- Если UI включён и URL известен → `enabled=true`, `ui_url="http://localhost:<port>"`.
- Если UI выключён или URL недоступен → `enabled=false`, `ui_url=null` (без exception).
