# Документация BSL Gradual Type System

Этот каталог хранит долгоживущую документацию проекта. Если нужен быстрый agent-facing onboarding, начинайте с `docs/agent/index.md`, а не с исторических roadmap-документов.

## Быстрый вход

- `../AGENTS.md` — канонический workflow и root policy
- `agent/index.md` — curated индекс для нового агента
- `guides/development-workflow.md` — живые команды сборки, запуска и проверки
- `BUILD_GUIDE.md` — build/package guide

## Разделы

- `agent/` — curated agent-facing docs, runbook и traceability
- `architecture/` — архитектурные описания и decomposition docs
- `api/` — web/API reference
- `guides/` — developer workflows и tooling guides
- `reference/` — reference docs и target architecture

## Полезные ссылки

- `../README.md` — project overview
- `../CONTRIBUTING.md` — contribution expectations
- `guides/tooling-guide.md` — tooling and MCP notes
- `architecture/type_system_architecture.md` — high-level architecture
