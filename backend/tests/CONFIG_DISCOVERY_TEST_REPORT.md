## Краткое описание изменений

### Проблема
Раньше парсер искал `Configuration.xml` прямо в указанной папке:
```
examples/conf/Configuration.xml  ← НЕ НАЙДЕНО
```

Но реальная структура:
```
examples/conf/
├── conf_test/           ← Configuration.xml здесь
│   └── Configuration.xml
└── ext_test/            ← Расширение
    └── Configuration.xml
```

### Решение
Добавлен метод `find_configuration_folder()` (строки 133-170):

1. **Обратная совместимость**: Сначала проверяет `Configuration.xml` прямо в `base_path`
2. **Автообнаружение**: Если не найден — сканирует прямые подпапки
3. **Первая найденная**: Возвращает первую подпапку с `Configuration.xml`
4. **Нерекурсивное сканирование**: НЕ сканирует вложенные подпапки глубже 1 уровня

## Обнаруженные особенности

### ✅ Что работает корректно

1. **Обратная совместимость**: `examples/conf/conf_test` → прямой путь работает
2. **Автообнаружение**: `examples/conf` → находит `conf_test/Configuration.xml`
3. **Множественные конфигурации**: Возвращает ПЕРВУЮ найденную (не все)
4. **Пустые подпапки**: Корректно пропускаются без ошибок
5. **Русские пути**: Кириллица в путях обрабатывается корректно
6. **Сообщения об ошибках**: Информативные и понятные

### ⚠️ Проектные ограничения (приемлемы)

1. **Нерекурсивное сканирование**:
   - Сканируются ТОЛЬКО прямые подпапки (1 уровень вложенности)
   - Глубоко вложенные конфигурации (src/cf/Configuration.xml) НЕ находятся
   - **Решение**: Указать путь до родительской папки (`src/` вместо `root/`)

2. **Первая найденная конфигурация**:
   - Если в папке несколько конфигураций (conf_test, ext_test) — загрузится первая
   - **Решение**: Указать прямой путь к нужной конфигурации

## Примеры использования

### ✅ Работает (обратная совместимость)
```rust
let discovery = ConfigurationDiscovery::new(
    Path::new("examples/conf/conf_test").to_path_buf()
);
let metadata = discovery.discover_all_metadata()?; // ✅ Найдёт 5 объектов
```

### ✅ НОВОЕ: Работает (автообнаружение)
```rust
let discovery = ConfigurationDiscovery::new(
    Path::new("examples/conf").to_path_buf()
);
let metadata = discovery.discover_all_metadata()?; // ✅ Найдёт conf_test или ext_test
```

### ❌ НЕ работает (глубокая вложенность)
```rust
let discovery = ConfigurationDiscovery::new(
    Path::new("project").to_path_buf()
);
// project/src/cf/Configuration.xml
let metadata = discovery.discover_all_metadata()?; // ❌ Не найдёт (>1 уровень)
```

**Решение:** Указать путь `project/src/`
