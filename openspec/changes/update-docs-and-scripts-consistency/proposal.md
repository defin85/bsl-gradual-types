# Предложение изменений: Синхронизация документации и скриптов с текущей структурой репозитория

## Зачем
Сейчас в репозитории есть несоответствия между документацией/скриптами и фактической структурой файлов. Это создаёт «ложные» точки входа для разработчиков и усложняет онбординг и поддержку:
- В документации встречаются ссылки на пути, которых больше нет (пример: `backend/src/system/tree_sitter_adapter.rs`).
- Скрипты/пометки прогресса milestones также ссылаются на устаревшие пути.

## Что меняется
- Привести документацию и скрипты, которые описывают файлы/пути, к текущей реальности репозитория.
- Уточнить актуальные пути/точки входа для tree-sitter адаптера и связанных компонентов.
- Добавить минимальную проверку/чек‑лист в документацию (без внедрения CI), чтобы такие расхождения не возвращались незаметно.

## Не цели
- Реализация функциональности tree-sitter адаптера, IR/CFG или иной логики анализа.
- Изменение архитектуры подсистемы парсинга.

## Влияние
- Только на разработческую документацию и поддерживающие скрипты (ожидаются правки в `docs/**` и `scripts/**`).
- На пользователей расширения/CLI рантайм‑поведение не влияет.

## Критерии готовности
- В репозитории не остаётся ссылок на несуществующий путь `backend/src/system/tree_sitter_adapter.rs`.
- Документация указывает корректные актуальные файлы/модули для tree-sitter адаптера.
