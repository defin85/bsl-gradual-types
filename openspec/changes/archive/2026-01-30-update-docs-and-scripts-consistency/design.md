# Дизайн: минимальная синхронизация ссылок на файлы

## Подход
- Исправлять ссылки точечно, без переосмысления архитектуры.
- Предпочитать ссылки на актуальные точки входа (модули/реэкспорты), а не исторические файлы.
- Если в документации требуется «исторический» пример — явно помечать как архивный контент и не использовать его как команду/инструкцию.

## Риски
- Непреднамеренно «законсервировать» устаревшее описание. Снижается через короткий ручной чек‑лист и поиск по репозиторию.
