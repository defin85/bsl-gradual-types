# Change: Исправить обобщённое `Для` (первый неожиданный токен), origin для эвристик и masking для многострочных срезов

## Why
В change `improve-syntax-diagnostics-related-and-linecap` добавлены:
- строгий line-cap (≤1 синтаксическая диагностика на строку),
- masking строк/комментариев,
- обобщённое правило `Для` (“ожидается `Цикл`” + span на неожиданный токен),
- related enrichment для незакрытой `Попытка`.

Однако в реализации выявлены риски/несоответствия:
1) Правило `Для` выбирает **последний** токен в диапазоне между `По` и `Цикл`, что расходится с требованием “первый неожиданный токен”
   и может давать нестабильный UX при нескольких лишних токенах.
2) Приоритизация line-cap отличает эвристики (semicolon/`Новый`) от parser-derived diagnostics через сравнение текста message,
   что хрупко и может сломаться при рефакторинге сообщений.
3) Masking для `//` в `ParseError`-срезах (которые могут содержать newline) сейчас маскирует до конца среза, а не до конца строки,
   что может скрывать ключевые слова на следующих строках и мешать корректным rewrite/enrich.

## What Changes
- Исправить обобщённое правило `Для`: span указывает на **первый** неожиданный токен между `По` и `Цикл` (при наличии нескольких).
- Устойчиво маркировать origin синтаксических diagnostics (parser vs heuristics) без зависимости от текста message,
  чтобы line-cap приоритизация оставалась стабильной.
- Улучшить masking для многострочных срезов: `//` маскируется до конца строки (до `\n`), а затем masking продолжается.
- Добавить/усилить тесты на:
  - несколько лишних токенов в `Для` (`abc def` → подсветка `abc`),
  - `Шаг` в комментарии (`// Шаг`) не триггерит правило,
  - line-cap приоритизация не зависит от message (структурный origin).

## Impact
- Affected specs:
  - `bsl-intellisense-v2` (точность span и предсказуемость синтаксических diagnostics)
- Affected code:
  - `syntax/src/tree_sitter_adapter/syntax_error_enhancers.rs`
  - `syntax/src/tree_sitter_adapter/mod.rs`
  - тесты `syntax/`

## Non-Goals
- Изменение грамматики `tree-sitter-bsl`.
- Изменение внешнего API LSP, кроме улучшения related/diagnostics контента.
