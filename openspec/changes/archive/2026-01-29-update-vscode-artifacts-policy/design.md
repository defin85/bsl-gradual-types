# Дизайн: артефакты сборки как локальный результат

## Принцип
`out/**` и `.vsix` — это производные артефакты. Их место — локальная рабочая директория или система релизов (например, GitHub Releases), но не git‑история исходников.

## Следующий шаг (вне scope)
Отдельный change может добавить релизный pipeline (CI) для сборки и публикации `.vsix`.
