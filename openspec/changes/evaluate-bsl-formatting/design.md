# Design: formatting strategy for BSL

## Вопрос, который решаем
Какой форматтер BSL мы считаем “каноничным” для этого проекта и как он интегрируется в IDE (VS Code через LSP).

## Критерии выбора
- Детерминизм (одинаковый ввод → одинаковый вывод).
- Минимальный diff (не “переписывает” код целиком).
- Производительность (интерактивность).
- Корректность для BSL синтаксиса (включая директивы/препроцессор).
- Совместимость со стилем команды (настройки/конфиг).
