## Проблема с enum_values

**Текущая ситуация:**
- Frontend и Backend DTO обновлены с полем `enum_values`
- API возвращает `"enumValues": null` для всех типов
- HTML структура корректна (проверено в examples/syntax_helper/rebuilt.shcntx_ru)
- `extract_enum_values_from_html()` вызывается, но не извлекает значения

**Гипотеза после рефакторинга:**
- `extract_members_from_section()` может некорректно обрабатывать секцию "Значения" (без двоеточия)
- Возможно проблема с сопоставлением текста заголовка
- Debug логирование в отдельном модуле позволит точно определить проблему
