# VSCode Extension Build Scripts

Скрипты для автоматизации сборки и подготовки расширения.

## copy-binaries.js

Автоматическое копирование актуальных Rust бинарников в директорию расширения.

### Функции

- ✅ Проверка наличия release бинарников
- ✅ Автоматическая сборка если бинарники отсутствуют
- ✅ Проверка актуальности по времени модификации
- ✅ Пропуск копирования если бинарник уже актуален
- ✅ Статистика копирования
- ✅ Цветной вывод в консоль

### Использование

```bash
# Автоматическое копирование (пропускает актуальные файлы)
npm run copy-binaries

# Принудительное копирование всех бинарников
npm run copy-binaries:force
```

### Интеграция

Скрипт автоматически запускается перед:
- `npm run compile` - компиляция TypeScript
- `npm run package` - создание production сборки
- `npm run vscode:prepublish` - подготовка к публикации

### Конфигурация бинарников

В `copy-binaries.js` определены следующие бинарники:

```javascript
const BINARIES = [
    {
        name: 'LSP Server',
        source: 'bsl-lsp-server.exe',  // Имя в target/release/
        target: 'lsp-server.exe',       // Имя в vscode-extension/bin/
        description: 'Language Server Protocol server для VSCode'
    }
];
```

### Добавление новых бинарников

Для добавления нового бинарника в расширение:

1. Соберите бинарник в release режиме:
   ```bash
   cargo build --release --bin my-new-binary
   ```

2. Добавьте конфигурацию в `BINARIES` массив:
   ```javascript
   {
       name: 'My New Binary',
       source: 'my-new-binary.exe',
       target: 'my_binary.exe',
       description: 'Описание назначения бинарника'
   }
   ```

3. Запустите копирование:
   ```bash
   npm run copy-binaries
   ```

### Обработка ошибок

Скрипт завершится с кодом 1 в случае:
- ❌ Исходный бинарник не найден в `target/release/`
- ❌ Ошибка при копировании файла
- ❌ Ошибка сборки Rust бинарников

### Технические детали

**Проверка актуальности:**
Скрипт сравнивает время модификации (`mtime`) исходного файла и целевого файла:
- Если целевой файл новее или равен → пропускается
- Если целевой файл старше → копируется
- Если целевой файл не существует → копируется

**Автоматическая сборка:**
Если `target/release/` не существует или используется флаг `--force`, скрипт автоматически запускает:
```bash
cargo build --release --bin bsl-lsp-server
```

**Кросс-платформенность:**
Скрипт использует `path.join()` для корректной работы на Windows, macOS и Linux.
